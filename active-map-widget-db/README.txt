知遇 · 桌面 AI 探索伴生体（数据库版）

这是一个带 SQLite 数据库的可运行版本。

运行方法：
1. 安装 Python 3.
2. 在这个文件夹里执行：python app.py
3. 打开：http://127.0.0.1:8123

功能：
- 内容推送来自 SQLite 数据库
- 默认关键词为流行乐、羽毛球、电影、游戏、旅行、美食等生活兴趣
- 服务启动后会从公开新闻 RSS 拉取关键词相关新闻或有趣内容
- 在线内容每 30 分钟自动更新一次，网络不可用时继续使用本地内容
- 推荐排序会综合新闻新鲜度、用户略过的边界、已看内容降权和分类去重
- 轨迹只增不减：用户对一张卡做出保留或略过后，该关键词会被记录到地图
- 点击“跳过 / 继续探索”会写入数据库
- 可以在页面底部新增内容，刷新后仍然保留
- 不需要额外安装 Flask 或其他第三方包

说明：
- 如果你要发给别人，直接把整个文件夹压缩即可
- 第一次运行后会自动生成 data/app.db
